About This Project

This project demonstrates a production-style, automated Continuous Integration and Continuous Deployment (CI/CD) pipeline built entirely using GitHub cloud infrastructure.

Key Highlights:

  • Zero Local Tools: No local Docker, Git CLI, or external IDE setup required.
  • Automated Testing: Pre-deployment integrity checks on web artifacts.
  • Continuous Delivery: Instant updates published to GitHub Pages upon merge/push.
