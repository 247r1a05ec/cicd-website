Automated Pipeline Breakdown

Stage 1: Version Control Push
Developer commits and pushes code directly to the main branch via the GitHub web interface.
Stage 2: Continuous Integration (CI)
GitHub Actions provisions an ephemeral ubuntu-latest runner. It checks out the workspace, validates that all HTML assets exist, and confirms non-zero file sizes.
Stage 3: Continuous Deployment (CD)
Once tests succeed, the runner bundles all website artifacts and deploys them to GitHub Pages with TLS encryption.
